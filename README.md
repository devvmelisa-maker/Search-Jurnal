# Search-Jurnal
Personal terminal tools for macOS — includes a custom `jurnal` command to search academic journals across multiple platforms at once.

Jujur, aku bukan developer pro atau orang yang jago terminal. Aku cuma mahasiswa yang capek buka satu-satu portal jurnal setiap kali mau nyari referensi. Dari rasa capek itu, kepikiran — *"kenapa gak
  sekalian aja?"* — dan lahirlah command `jurnal` ini.
  
  Ini bukan sesuatu yang wah atau rumit. Tapi kalau ternyata ada yang terbantu, aku senang sekali. 😊
  
  Kalau kamu punya saran — mau itu portal jurnal baru yang perlu ditambahkan, atau ada yang kurang tepat — feel free buat buka **Issue** atau **Pull Request**. Aku terbuka banget!

### 📚 `jurnal` — Pencarian Jurnal Sekaligus
  
  Satu command, semua portal jurnal terbuka sekaligus di browser.
  
  #### Cara pakai
  
  ```bash
  jurnal <kata kunci>
  
  Contoh
  
  jurnal machine learning sentiment analysis
  
  Portal yang dibuka:
  - ACM Digital Library
  - ScienceDirect
  - Springer
  - Scopus
  - IEEE
  - DOAJ
  - Dimensions
  - Neliti
  - OneSearch
  - Perpusnas
  - Kemdiktisaintek

⚙️ Instalasi
  
  1. Clone repo ini
  2. Copy isi jurnal.zsh ke ~/.zshrc
  3. Jalankan source ~/.zshrc
  4. Selesai!
  
  About This Repo
  
  Honestly, I'm not a pro developer or a terminal wizard. I'm just a student who got tired of opening academic journal portals one by one every time I needed references. Out of that frustration came this
  idea — "why not open them all at once?" — and that's how the jurnal command was born.
  
  This isn't anything fancy or complicated. But if it happens to help someone out there, that makes me really happy. 😊
  
  If you have suggestions — whether it's a new journal portal to add, or something that doesn't seem right — feel free to open an Issue or Pull Request. I'm very open to it!
